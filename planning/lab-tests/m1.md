# Lab-test evidence — M1: Prove the Wiring

**Machine:** Apple Silicon (arm64), 16 GB RAM  
**Date:** 2026-10-21  
**Runtime:** Rancher Desktop — docker client `29.5.3-rd`, server `29.5.2` (dockerd/moby)  
**Model server:** Ollama `0.40.7` (native, MLX runner), serving on `:11434`  
**Model:** `qwen3.5:2b` (3.1 GB on disk, mxfp8, 3.8 GB loaded, 100% GPU, 4096 context)  
**Validated by:** automated Bash tool calls with `PATH="$HOME/.rd/bin:$PATH"` prefix

> Note: in lab.md, all commands use plain `docker` (learners have it on PATH).
> In this validation session, every docker command was prefixed with `PATH="$HOME/.rd/bin:$PATH"`.
> `qwen3.5:2b` thinks by default. Every call below carries the switch-off (`"think": false` on native endpoints, `"reasoning_effort": "none"` on `/v1`).

## Lab Step 3 — container calls the model (with `"think": false`)

**Command:**
```bash
docker run --rm curlimages/curl:latest -s http://host.docker.internal:11434/api/generate \
  -d '{"model":"qwen3.5:2b","prompt":"Say hi in 5 words.","stream":false,"think":false}'
```

**Real output:**
```json
{"model":"qwen3.5:2b","created_at":"2026-10-21T08:12:43.555791Z","response":"Hello there!
```
